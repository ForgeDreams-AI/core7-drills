# Core 7 Drills — Walk-Through Games

Walk-through training games for the Phoenix Fire Department's seven Core 7 drills, built from the Recruit Training page videos (phxfd YouTube).

The seven (in order):
1. SCBA — Donning (35-second standard)
2. Captain side plug
3. Engineer side plug
4. Attack line/clamp
5. Horizontal
6. Roof cut
7. Ladders

Drill 1 (SCBA) is live. The rest are coming, one at a time, after the SCBA game gets a verdict.

Source video: "Donning SCBA" — https://www.youtube.com/watch?v=rluAjqRgv5I
